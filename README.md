# 부용고등학교 1학년 모의고사 분석 대시보드

2026학년도 3월 부용고 1학년 집계 성적과 3·6월 전국 통계를 비교하는 정적 GitHub Pages 사이트입니다.

## 대시보드

- `index.html`: 전국 대비, 과목별 심층, 전국 3→6월 흐름, 학습 참고점 탭
- `styles.css`: 반응형 화면 스타일
- `app.js`: KPI 계산, 과목 선택, Chart.js 그래프
- `data.js`: 부용고 3월 학년 평균과 전국 3·6월 통계
- `.nojekyll`: GitHub Pages 정적 파일 설정

## 자료 범위와 기준

- 부용고 학교 평균은 `성적일람표(3월 1학년 전체).pdf`의 학교평균 행에서 국어·수학·사회탐구·과학탐구 표준점수 평균을 입력했습니다. 성명이나 학생별 점수는 게시하지 않습니다.
- 3월 전국 원점수 평균은 `2-1. 2026학년도 3월 고1 전국연합학력평가 통계자료.xlsx`의 영역별 원점수 통계를 사용했습니다.
- 3월 전국 표준점수 평균은 같은 파일의 표준점수 누적도수와 인원을 사용해 가중평균으로 계산했습니다.
- 6월 전국 원점수 평균은 `2026학년도 6월 고1 전국연합학력평가 성적 분석.pdf` 7쪽의 통계를 사용했습니다.
- 부용고 6월·9월 성적은 제공되지 않아 학교 회차별 향상 분석을 하지 않습니다. 전국 3월·6월 변화는 전국 통계끼리만 비교합니다.

자료를 갱신할 때는 `data.js`의 출처·측정 기준을 유지하고, 학교 6월 성적이 확보되기 전까지 학교의 3→6월 변화를 입력하지 않습니다.

## 배포

GitHub Pages에서 `main` 브랜치 루트 디렉터리를 게시 대상으로 사용합니다. Chart.js는 jsDelivr CDN에서 불러옵니다.
